# Верификация для поисковых систем

Для верификации сайта в поисковых системах поместите сюда соответствующие файлы:

## Google Search Console
- Файл `google[код].html`

## Яндекс.Вебмастер
- Файл `yandex_[код].html`

## Bing Webmaster Tools
- Файл `BingSiteAuth.xml`

Эти файлы должны быть доступны по адресу:
https://safe-avtopodbor.ru/.well-known/[имя_файла]
